# ⚙️ Mechanical Engineer Portfolio - Praveen Kumar

A high-performance, **3D Animated Portfolio Website** designed for a Mechanical Engineer. This project purely uses **HTML, CSS, and JavaScript** (No external frameworks) to deliver a unique, industrial aesthetic with futuristic, robotic animations.

## ✨ Key Features

### 🎨 Visual & Aesthetic
*   **Futuristic Chip Logo**: A custom-designed navbar logo with a "scanning" sheen effect and rotating neon RGB borders.
*   **Recruiter Intro Overlay**: A cinematic **3.5-second System Boot** sequence with rotating gears, typing terminal text, and a loading bar.
*   **Magical RGB Borders**: Project cards feature a self-rotating, multi-color conic gradient border that changes colors (Cyber Blue, Neon Pink, Industrial Orange).
*   **Mechanical Theme**: Gear backgrounds, hex-frames, and industrial color palette (Steel Gray, Navy, Safety Orange).

### ⚡ Interactive Elements
*   **Smart Contact Cards**: "Get In Touch" section features interactive buttons for Phone (Ringing animation), Email (Floating animation), and LinkedIn (Shaking animation).
*   **Typewriter Effect**: Dynamic text changing between "Production Engineer", "Maintenance Engineer", etc.
*   **Scroll Reveal**: Elements fade in, slide up, or slide in from sides as you scroll.
*   **Responsive Grid**: A robust CSS Grid layout for the Navbar that adapts perfectly to Mobile (Hamburger menu) and Desktop.

### 🛠️ Tech Stack
*   **HTML5**: Semantic structure.
*   **CSS3**: CSS Variables, Grid/Flexbox, Keyframe Animations, Pseudo-elements (`::before/::after`).
*   **JavaScript (ES6)**: Intersection Observer for scroll animations, Typewriter logic, Theme toggling.

## 📂 Project Structure
*   `index.html`: Main entry point with semantic sections.
*   `css/style.css`: 2000+ lines of custom styling, variables, and media queries.
*   `js/script.js`: Logic for loader, scroll effects, and mobile menu.
*   `assets/`: Contains images and the resume file.
